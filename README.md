## Key Features and Functionality
Homepage with a two-column hero (CSS Grid), introduction, and call to action.
About Us page with company history, mission, vision, and a responsive team grid.
Services page detailing Residential Wiring, Commercial Installations, and Fault Finding & Maintenance, styled as a responsive 3-column card grid.
Enquiry page with a styled quote-request form (custom focus states, validation-ready).
Contact page with two locations, embedded maps, and a contact form, in a responsive two-column layout that stacks on smaller screens.
Fully responsive across desktop, tablet (≤768px), and mobile (≤480px) breakpoints.
Responsive images using srcset/sizes at 480w/800w/1200w for key photos.
Visible keyboard focus states and prefers-reduced-motion support for accessibility.
